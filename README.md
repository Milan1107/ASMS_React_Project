# Agency Stock Management System (ASMS)

## Overview
The Agency Stock Management System (ASMS) is a program written in Assembly language that manages the inventory and stock of products for an agency. The system allows the user to perform tasks such as adding new stock, updating existing stock levels, viewing inventory, and deleting products from the stock. This project is a demonstration of low-level programming using Assembly, focusing on file handling, input/output processing, memory management, and basic arithmetic operations. 

The project is implemented using **NASM** (Netwide Assembler) and is compatible with **Linux-based** operating systems, running on **x86-64 architecture**.

## Features
- **Efficient memory management** for handling product details, such as names, quantities, and prices.
- **Input validation and error handling** for robust user interaction.
- **Basic arithmetic operations** to calculate stock values and update quantities.
- **File handling** for storing and retrieving stock data from a file to maintain persistence.
- **User-friendly menu** for managing different operations, such as adding, viewing, or deleting stock items.

## Requirements
To build and run this project, you will need:
- **NASM** (Netwide Assembler) version 2.x or later.
- **LD** (GNU Linker) for linking the object files.
- **Linux OS** (or any system supporting x86-64 assembly language).
- Basic knowledge of Assembly language and x86-64 architecture.
